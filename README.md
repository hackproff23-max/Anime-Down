# Anime-Down

Navegador + baixador de vídeos, **sem anúncios**.

- Navegador embutido com bloqueio de domínios de anúncios e pop-ups
- Detecta vídeos da página (.mp4, .m3u8, .mkv, .webm) e baixa com um toque
- Suporta HLS (.m3u8), inclusive criptografia AES-128
- Downloads em segundo plano com notificação; salva em `Download/Anime-Down`
- APK assinado (keystore em `keystore/`), build pelo GitHub Actions

Não baixa vídeos com DRM (Netflix, Crunchyroll etc.). Use só com conteúdo que você tem direito de baixar.
