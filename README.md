# Anime-Down

Navegador + baixador de vídeos, **sem anúncios**.

- Navegador embutido com bloqueio de domínios de anúncios e pop-ups
- Detecta vídeos da página e mostra as qualidades (144p, 240p, 360p, 480p, 720p, 1080p...) com o tamanho de cada uma
- Download rápido: várias conexões em paralelo (4, 8, 16 ou 32 nas configurações)
- Suporta HLS (.m3u8), inclusive criptografia AES-128
- Barra de progresso na tela principal e tela de Downloads com porcentagem, velocidade e tempo restante
- Pausar, continuar e trocar o link expirado sem recomeçar o download
- Salva em `Download/Anime-Down`
- APK assinado (keystore em `keystore/`), build pelo GitHub Actions

Não baixa vídeos com DRM. Use só com conteúdo que você tem direito de baixar.
